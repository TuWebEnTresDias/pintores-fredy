# Pintores Fredy

Sitio estático personalizado para Pintores Fredy, basado en la demo de pintores y adaptado con las fotos compartidas por el lead.

- URL prevista: https://tuwebentresdias.github.io/pintores-fredy/
- Contacto: enlaces directos a WhatsApp y teléfono.
- Alcance confirmado: trabajos en toda CABA.
- Servicios presentados a partir de las fotos: pintura interior, exteriores y fachadas, preparación de paredes y trabajos en altura.
- Las fotos se cargan desde el bucket público de Supabase compartido en el chat; no se copiaron a este repositorio.
- La página tiene `noindex,follow` hasta que se apruebe la versión.

El sitio no incluye formularios ni backend. Revisar `AGENTS.md` antes de modificar el contenido.
